# Powah: Beyond Nitro

**Take your Powah setup beyond Nitro with four new endgame tiers: Aurion, Viberion, Oblivion and Singularity.**

Create tier crystals in the Energizing Orb using Allthemodium, Vibranium and Unobtainium, then craft upgraded equipment with familiar Powah recipes.

## Features

- Four tiers with 4x, 16x, 64x and 256x scaling from the matching Nitro configuration.
- Upgraded versions of every Nitro block family: generators, reactors, energy cells, cables, rods, Ender devices, player transmitters, hoppers, dischargers and crystal blocks.
- Matching capacitors and rechargeable batteries.
- Nine crystals combine into a storage block and unpack back into nine crystals.
- Familiar recipe quantities: cables in batches of 6 or 12, reactors and Ender Gates in batches of 4.
- Tier-coloured machines and crystals, with names such as **Energy Cell (Aurion)**.

## Requirements

**Minecraft 1.21.1 · NeoForge 21.1.251+ within the 21.1 series · Java 21**

Requires **Powah! (Rearchitected) 6.2.10**, **Allthemodium**, and their normal dependencies. Install the addon on both client and server.

## Good to know

Power values scale from your Powah configuration and remain subject to FE API limits. Empty stored energy and inventories before crafting machine upgrades. Reactors still require 36 blocks to assemble.

Mod ID: `powahbeyondnitro`. Older development builds used `beyondnitro`; no automatic world migration is included. Use a fresh world for the renamed version.

An independent addon for Powah, not an official Powah or All the Mods release.

**Short summary:** Four endgame Powah tiers, Allthemodium-powered crystal progression, and upgraded versions of every Nitro block family.

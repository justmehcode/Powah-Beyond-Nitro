# Powah: Beyond Nitro

A NeoForge addon that adds four new tiers beyond Nitro: **Aurion, Viberion, Oblivion, and Singularity**.

## Features

- Upgraded versions of every Powah block.
- New crystals, capacitors, and batteries.
- Energizing Orb progression using Allthemodium metals.
- Familiar Powah crafting recipes and tier-coloured textures.

## Requirements

- Minecraft **1.21.1**
- NeoForge **21.1.251+** (1.21.1)
- Powah! (Rearchitected) **6.2.10**
- Allthemodium and the dependencies required by these mods
- Java **21**

Place the addon JAR in your `mods` folder on both client and server.

## Building

```sh
./gradlew assemble
```

On Windows, use `gradlew.bat assemble`. The JAR is generated in `build/libs`.

## Notes

- Empty machines and batteries before crafting upgrades.
